# LIFENEXUS HackDay Documentation Pack

This folder contains the six core planning documents for the LIFENEXUS
hackathon project.

1.  `PRD.md` --- Product Requirements Document
2.  `ARCHITECTURE.md` --- System architecture, data model and technical
    flow
3.  `RULES.md` --- Development, security, AI, Git and hackathon rules
4.  `DESIGN.md` --- Visual identity, orange/peach theme, typography,
    components and UX rules
5.  `TASK.md` --- Phase-by-phase 8-hour build plan and submission
    checklist
6.  `MEMORY.md` --- Personal Memory Engine model, graph, timeline,
    retrieval and AI context rules

## Product

**LIFENEXUS**\
*Everything you've done. Connected.*

## Core concept

LIFENEXUS turns scattered personal digital traces into a connected
Personal Knowledge Graph and Life Timeline, with natural-language Life
Search and source-backed insights.
